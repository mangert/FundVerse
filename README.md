🧩 Обзор последних изменений смарт-контрактов FundVerse
Основные обновления

🛰️ Chainlink Status Dispatcher
Добавлен контракт StatusDispatcher для автоматизации смены статусов кампаний через Chainlink Automation.
В контрактах кампаний реализованы функции регистрации и отписки кампаний в диспетчере.

⚙️ Минимальные прокси (EIP-1167)
Механизм создания кампаний переведён на шаблон минимального прокси.
Контракты кампаний и фабрика адаптированы под прокси-развёртывание, что значительно снижает газовые издержки и упрощает обновления логики.

🎯 Рефакторинг управления статусами
Универсальная функция смены статуса удалена.
Вместо неё добавлены три явные функции:

cancelCampaign()

stopCampaign()

resumeCampaign()
Такой подход делает логику статусов более прозрачной и безопасной.

🧹 Упрощение интерфейса
Удалена вспомогательная функция для преобразования статусов в строковое представление — теперь форматирование статусов выполняется на фронтенде.

🔒 Анализ и мелкие правки

Проведён статический анализ с помощью Solhint и Slither.

Исправлены незначительные замечания (например, immutable, indexed, оформление кода, порядок функций).

Подтверждено отсутствие критических уязвимостей и проблем с безопасностью.

✅ Результат

Контракты оптимизированы по структуре, безопасности и читаемости кода, подготовлены к дальнейшей интеграции с Chainlink Automation и фронтендом.
